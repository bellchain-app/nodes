# Community nodes · Bausteine der Community

One node per file: `community/<name>.json` with the id `custom.<name>`. Import a file in the editor under **Import** and the node appears under **Custom nodes**. How to contribute: [CONTRIBUTING.md](../CONTRIBUTING.md).

Ein Baustein je Datei: `community/<name>.json` mit der Kennung `custom.<name>`. Im Editor unter **Importieren** laden, dann steht der Baustein unter **Eigene Bausteine**. So trägst du bei: [CONTRIBUTING.de.md](../CONTRIBUTING.de.md).

Every file here passed the check (`node scripts/check.mjs`) and a review: author, texts in German and English, and tests with reference values over the price data in `fixtures/`.

Jede Datei hier hat die Prüfung (`node scripts/check.mjs`) und ein Review bestanden: Autor, Texte auf Deutsch und Englisch und Tests mit Referenzwerten über die Kursdaten in `fixtures/`.
